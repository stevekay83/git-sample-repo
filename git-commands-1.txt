-------------------------------------------------Git Commands---------------------------------------------------
git status-----------------------------------------------> prints the status of the Git repository
git init-------------------------------------------------> initializes the Git repository
git config --global user.name "Let's Kode It"------------> specifies username globally
git config --global user.email letskodeit@gmail.com------> specifies email globally
git config user.name "Let's Kode It"---------------------> specifies username for particular repository
git config user.email letskodeit@gmail.com---------------> specifies email for particular repository
git add--------------------------------------------------> adds file to staging environment
git commit -m ""-----------------------------------------> commits file to local Git repository
git log--------------------------------------------------> checks file log history
Git diff <filename>--------------------------------------> checks changes made to file with existing file
git remote add origin <GitHub Repository URL>------------> establish connection to the remote Github Repository
git push origin master-----------------------------------> push to master branch
